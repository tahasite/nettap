## 🎯 NETtap چیست؟

**NETtap** یک پنل حرفه‌ای مدیریت اشتراک VPN است که به عنوان یک **پروکسی هوشمند DNS** بین مشتریان شما و ارائه‌دهندگان VPN عمل می‌کند. برخلاف پنل‌های سنتی VPN، NETtap ترافیک را از سرور شما عبور نمی‌دهد — یعنی **بدون مصرف پهنای باند، بدون افت سرعت، و مقیاس‌پذیری نامحدود**.

مناسب برای کسانی که می‌خواهند **کسب و کار فروش VPN** راه‌اندازی کنند، بدون پیچیدگی مدیریت سرورهای VPN.

### 🔥 نحوه کار

```
┌─────────────┐   درخواست DNS   ┌─────────────┐   اتصال مستقیم        ┌──────────────┐
│   مشتری     │ ──────────────> │   NETtap    │ ────────────────────> │  ارائه‌دهنده   │
└─────────────┘                 │ (سرور شما)   │                       │     VPN      │
                                └─────────────┘                       └──────────────┘
                                       │
                                فقط DNS از اینجا رد میشه
                                مصرف پهنای باند صفر!
```

<br>

## 💰 پتانسیل درآمد

### چرا با NETtap کسب‌وکار VPN راه‌اندازی کنیم؟

| فاکتور | جزئیات |
|--------|---------|
| 💵 **هزینه شروع** | ماهی ۵ دلار (یک VPS کوچک) |
| 📈 **حاشیه سود** | ۹۰ تا ۹۵ درصد |
| 🌍 **بازار جهانی** | میلیاردها کاربر نیاز به دسترسی VPN دارند |
| 📊 **درآمد ماهانه** | ۱۰۰ تا ۵۰۰۰+ دلار (بستگی به مقیاس) |
| ⚡ **زمان راه‌اندازی** | ۵ دقیقه با نصب تک‌دستوری |

### نمونه درآمد:
- **۵۰ کاربر × ماهی ۳ دلار** = ۱۵۰ دلار سود در ماه
- **۲۰۰ کاربر × ماهی ۳ دلار** = ۶۰۰ دلار سود در ماه
- **۱۰۰۰ کاربر × ماهی ۳ دلار** = ۳۰۰۰ دلار سود در ماه

## ✨ امکانات

### 🎨 پنل مدیریت مدرن

- **چندزبانه**: فارسی، English، Русский
- **تم تاریک/روشن**: تشخیص خودکار از دستگاه کاربر
- **کاملاً ریسپانسیو**: عالی روی موبایل و دسکتاپ
- **بروزرسانی زنده**: آمار و مانیتورینگ لحظه‌ای

### 🤖 ربات تلگرام کامل

- **ویزارد تنظیم خودکار**: پیکربندی با یک کلیک
- **کانال‌های عضویت اجباری**: افزایش ممبر کانال تلگرام
- **سیستم پرداخت**: تایید دستی با رسید
- **سیستم تست رایگان**: ضداسپم با تایید شماره موبایل
- **سیستم معرفی**: ۲۰٪ کمیسیون معرفی دوستان
- **پنل ادمین**: کنترل کامل از داخل ربات

### 🌐 سیستم DNS هوشمند

- **یکپارچه با CoreDNS**: سرور DNS محلی فوق سریع
- **ساب‌دامنه اختصاصی**: هر کاربر دامنه شخصی‌سازی شده
- **مسدودسازی لحظه‌ای**: بلاک کاربران با یک کلیک
- **بدون مصرف ترافیک**: فقط DNS Query، بدون ترافیک VPN

### 👥 مدیریت کاربران

- **پلن‌های سریع**: از ۳۰ دقیقه تا ۹۰ روز
- **سیستم گروه**: اختصاص کانفیگ‌های مختلف به کاربران مختلف
- **شروع تایمر از اولین اتصال**: محاسبه عادلانه
- **انقضا خودکار**: مدیریت خودکار اشتراک
- **خروجی QR Code**: اشتراک‌گذاری آسان با مشتری

### 💳 سیستم پرداخت انعطاف‌پذیر

- **کارت به کارت**: تایید رسید توسط ادمین
- **روش‌های متنوع**: قابل گسترش با درگاه‌های جدید
- **مدیریت سفارش**: تاریخچه کامل سفارشات

## 🚀 نصب سریع

### پیش‌نیازها

- Ubuntu 20.04/22.04/24.04 یا Debian 11/12
- دسترسی root
- حداقل 1GB RAM و 1 CPU
- یک دامنه (توصیه می‌شود)

### نصب با یک دستور

```bash
bash <(curl -sSL https://raw.githubusercontent.com/tahasite/nettap/main/scripts/install.sh)
```

همین! نصب‌کننده این کارها رو انجام میده:

1. ✅ بررسی نیازمندی‌های سیستم
2. ✅ نصب تمام پیش‌نیازها (Python, Nginx, CoreDNS)
3. ✅ راه‌اندازی دیتابیس و سرویس‌ها
4. ✅ پیکربندی گواهی SSL
5. ✅ ساخت اکانت ادمین
6. ✅ نمایش اطلاعات دسترسی

<br>

## 🎮 دستورات مدیریت

بعد از نصب، به راحتی NETtap رو مدیریت کن:

```bash
nettap              # باز کردن منوی کنترل
nettap start        # شروع تمام سرویس‌ها
nettap stop         # توقف تمام سرویس‌ها
nettap restart      # ری‌استارت
nettap status       # بررسی وضعیت
nettap logs         # نمایش لاگ زنده
nettap update       # آپدیت به آخرین نسخه
nettap backup       # بکاپ‌گیری
nettap uninstall    # حذف کامل
```
